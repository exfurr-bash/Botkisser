## ⚙️ Instalação

1. Clone o repositório:

```bash
git clone https://github.com/seuuser/botkisserUwU.git
cd botkisserUwU
```
2. Crie um .env com:



DISCORD_TOKEN=seu_tokenzão
GOOGLE_API_KEY=sua_chave_linda

3. Instale as dependências (recomendo usar virtualenv):


```
pip install -r requirements.txt
```
4. Roda o bot:


```
python3 geminiuwu.py
```
